# 마이치(mych) 캐릭터 자산 제작 가이드

> **브랜드**: 마이치 (mych, My Cognitive Habit)
> **톤 방향**: 시나모롤·몰랑(Molang) 풍 일본 카와이 마스코트 (방향 F 확정 — 2026-06-11)
> **도구**: [gemini.google.com](https://gemini.google.com) (Nano Banana / Gemini 2.5 Flash Image, Gemini Pro 구독 활용)
> **저장 폴더**: `public/character-assets-local/{breed}/` (gitignore 처리 완료)
> **최종 업로드**: Supabase Storage `character-assets` 버킷
> **총 자산**: 4종 × 6표정 × 4트렌드 = 96장 + 카드 4장 = **100장**

---

## 1. 디자인 톤 — 절대 변경 금지 7원칙

작업 중 모델 출력이 흔들리면 이 표로 진단:

1. **2.5등신 비율** — 머리(약 60%) + 몸(약 30%) + 짧은 콩 모양 다리(약 10%)
2. **점 두 개 눈 + 작은 U자 입 + 분홍 볼터치 두 점** (감정 슬롯의 베이스)
3. **얇은 연한 갈색 외곽선 + 평면 채색 + 셀 셰이딩 한 톤만** (그라데이션·텍스처 X)
4. **흰색/크림 베이스 + 종별 시그니처 컬러 포인트 1색**
5. **굿즈/스티커 변환 가능한 명확한 실루엣**
6. **AI 평균치 카와이 톤 회피** — 시나모롤·몰랑 IP를 매번 직접 참조시킬 것
7. **정사각 1024×1024, 캐릭터 중앙, 단색 배경, 충분한 여백**

## 3. 4종 캐릭터 베이스 디자인

### 🐕 시바이누 (`shiba`) — 의욕폭주형
- **베이스 색**: 크림 화이트 얼굴/배 + 카멜·허니 옐로우 등·귀·꼬리
- **형태**: 작은 삼각 귀가 또렷이 세워짐, 짧고 살짝 말린 꼬리, 통통한 몸
- **시그니처**: 호기심 가득한 동그란 눈
- **인상**: 활기, 호기심, 한 발 앞서가는 친구

### 🐩 푸들 (`poodle`) — 완벽주의형
- **베이스 색**: 미색·오프화이트 + 옅은 라벤더(연보라) 포인트 (귀·발끝)
- **형태**: 곱슬털을 작은 구름 같은 실루엣 라인으로 단순화 (귀와 머리 위), 둥근 윤곽
- **시그니처**: 단정하게 가지런히 모은 두 앞발
- **인상**: 단정함, 깔끔함, 살짝 긴장한 우등생

### 🐈 코리안 숏헤어 (`korat`) — 마이페이스형
- **베이스 색**: 옅은 베이지·크림 + 머스타드 줄무늬 (이마·등·꼬리)
- **형태**: 살짝 길쭉한 얼굴, 뾰족 삼각 귀, 슬림한 꼬리(살짝 올림)
- **시그니처**: 살짝 옆을 보는 시크한 눈
- **인상**: 시크함, 마이페이스, 한 발 거리감

### 🐈‍⬛ 러시안블루 (`russian_blue`) — 번아웃취약형
- **베이스 색**: 옅은 블루그레이 전체 + 민트·세이지 포인트 (볼터치 옆·꼬리 끝)
- **형태**: 큰 둥근 머리, 작은 뾰족 귀, 짧고 통통한 꼬리, 큰 눈
- **시그니처**: 살짝 졸린 듯한 큰 눈
- **인상**: 조용함, 섬세함, 안아주고 싶은 친구

## 5. 표정 슬롯 (6종) — 종 공통

| 키 | 눈 | 입 | 볼터치 | 추가 디테일 |
|----|------|------|--------|-------------|
| `happy` | 반달 모양(웃는 눈) | 큰 U자 미소 | 분홍 진하게 | 양 앞발 살짝 위, 머리 위 작은 반짝 ✦ 1~2개 |
| `calm` | 작은 점 두 개 | 작은 U자 미소 | 분홍 옅게 | 어깨 풀린 편안한 좌위 |
| `neutral` | 작은 점 두 개 | 작고 짧은 일자 선 | 매우 옅음 | 똑바로 앉은 무표정 |
| `sad` | 작은 점(살짝 아래로) | 작은 ∩자 (아래로 처짐) | 옅음 | 살짝 고개 숙임, 어깨 처짐 |
| `angry` | 짧게 찌푸린 곡선 | 작은 시옷 입 (^) | 분홍 진하게 | 양 앞발 모음, 머리 위 작은 김 한 줄 ~ |
| `anxious` | 큰 동그라미 눈 + 작은 점 | 작고 떨리는 ∼ 곡선 | 옅음 | 몸 살짝 움츠림, 머리 위 작은 땀방울 💧 1개 |

## 6. 트렌드 슬롯 (4종) — 종 공통

| 키 | 자세 | 분위기/배경 디테일 |
|----|------|-------------------|
| `rising` | 살짝 들뜬 좌위, 꼬리 위쪽, 한쪽 발 살짝 듦 | 머리 주변 옅은 노랑/크림 반짝 ✦ 2~3개, 톤 살짝 밝게 |
| `stable` | 정자세 좌위, 두 앞발 가지런히, 꼬리 자연스럽게 | 배경 깨끗, 추가 요소 없음 |
| `declining` | 살짝 고개 기울임, 어깨 처짐, 꼬리 아래로 | 배경 옅은 라벤더그레이 톤, 주변 살짝 어둑함 |
| `crashing` | 무릎/배 모으고 웅크림, 작은 몸 | 머리 주변 옅은 회색 작은 점·먼지 2~3개, 배경 옅은 그레이 톤 |

Day 1 시바 1장을 컨텍스트 이미지로 첨부 + 표정·트렌드 슬롯만 바꿔서 23장 생성.

### Day 3 — 푸들 풀 변형 (23장)
### Day 4 — 코숏 풀 변형 (23장)
### Day 5 — 러시안블루 풀 변형 (23장)

- 4종 × 24장 = 96장 일관성 검수 (한 화면에 나열, 톤 일치 확인)

## 10. 변형 작업 방법 (Day 2~5 효율화)

96장을 매번 풀 프롬프트로 쓰면 톤이 흔들립니다. 대신:

1. **Day 1 핵심 4장을 컨텍스트 이미지로 첨부** (gemini.google.com에 드래그앤드롭)
2. 짧은 변형 요청만 입력:

```
첨부한 [시바 이미지]의 톤·디자인·비율을 정확히 유지하면서,
표정만 [§5 표정 슬롯 텍스트 복붙]
자세만 [§6 트렌드 슬롯 텍스트 복붙]
으로 변경해줘. 나머지 모든 요소(색·외곽선·매체·배경)는 그대로.
```

3. 결과가 흔들리면 풀 프롬프트(§11 형식)로 재요청.

## 12. 검수 체크리스트

Day 1과 Day 6에 각각 사용:

- [ ] 4종을 한 화면에 나열했을 때 같은 톤·매체로 보이는가
- [ ] 같은 종의 24장이 같은 캐릭터로 보이는가 (얼굴형·색·비율이 흔들리지 않음)

- [ ] 트렌드 4종이 분위기로 구분되는가 (rising 밝음, crashing 어둑함)
- [ ] 배경이 단색 크림·여백·정사각인가
- [ ] 머리:몸 비율이 약 60:40 유지되는가 (2.5등신)
- [ ] 외곽선이 얇고 연한 갈색인가 (검정·굵은 선 X)
- [ ] 사진/수채화/펠트/그림책 톤이 다시 끼어들지 않았는가
