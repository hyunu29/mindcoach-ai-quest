# 캐릭터 자산 생성 프롬프트 (수동 워크플로)

> **도구**: gemini.google.com (Gemini Pro 구독 활용, API 키 불필요)
> **저장 폴더**: `public/character-assets-local/{breed}/`
> **최종 명명**: `{emotion}_{trend}.png` 또는 `card.png` / `calm_stable.png`
> **디자인 문서**: `docs/plans/2026-06-09-character-mascot-system-design.md` §5

---

## 작업 일정 (총 6일차, ~8시간)

| 일차 | 작업 | 산출물 | 소요 |
|---|---|---|---|
| 1일차 | 키 이미지 4종 (calm × stable) | 4장 | 1시간 |
| 2일차 | 시바 변형 23장 | 23장 | 1.5시간 |
| 3일차 | 푸들 변형 23장 | 23장 | 1.5시간 |
| 4일차 | 코숏 변형 23장 | 23장 | 1.5시간 |
| 5일차 | 러시안블루 변형 23장 | 23장 | 1.5시간 |
| 6일차 | 96장 일괄 검수 + 재생성 | 검수 통과 96장 | 1시간 |

**중요**: 한 종은 같은 채팅 세션에서 끝까지 작업. 세션 끊기면 일관성 깨짐.

---

## 공통 가이드

### 사용 모델

gemini.google.com에서 자동으로 이미지 생성 모델로 라우팅됨 (보통 Imagen 또는 Nano Banana). 모델 강제 선택 불필요.

### 일관성 유지 핵심 규칙

1. **한 종 = 한 채팅 세션** (컨텍스트 유지)
2. 키 이미지 생성 후 다음 이미지 요청 시: **"이전 이미지와 동일한 캐릭터 유지"** 문구 반드시 포함
3. 마음에 안 들면 "조금 더 부드럽게", "표정만 바꾸고 외형 유지" 식으로 미세 조정
4. 외형 깨지면 키 이미지 다시 reference로 첨부 (드래그&드롭)

### 공통 스타일 키워드 (모든 프롬프트 헤더)

```
스타일: 귀엽고 부드러운 카와이 2D 일러스트, 단일 캐릭터, 
파스텔 색감 (민트/피치/크림/라벤더), 플랫 셰이딩에 부드러운 그라데이션, 
얇은 외곽선, 따뜻하고 지지적인 분위기, 
한국 수험생을 위한 멘탈헬스 앱용, 흰색~연한 배경 중앙 정렬,
산리오 + 모던 한국 일러스트 (Esther Bunny 톤) 블렌드.

금지: 사실적, 사진 같은, 무서운, 어두운, 잔혹한, 무기, 다중 캐릭터, 
텍스트, 워터마크, 흐릿, 변형된 신체, 위협적 표정.
```

### 저장 방법

1. 생성된 이미지 우클릭 → "이미지 다른 이름으로 저장"
2. 명명 규칙 따라 저장: `{breed}_{emotion}_{trend}.png`
3. `public/character-assets-local/{breed}/` 폴더로 이동

# 1일차 — 키 이미지 4장 (calm × stable)

**목표**: 4종 페르소나가 한 화면에 모였을 때 위화감 없는 톤 통일 키 이미지 확보. 이후 모든 변형의 reference.

**사전 준비**: 폴더 4개 확인.
```
public/character-assets-local/
├── shiba/
├── poodle/
├── korat/
└── russian_blue/
```

**작업 순서**: 4종 순서대로 채팅 세션 4개 따로 열기. 각 세션에서 아래 프롬프트 1개씩 입력.

### 1일차 검수 체크리스트

4장을 한 화면에 띄워놓고 확인:

- [ ] 4장의 **아트 스타일 톤이 통일**되어 있는가? (한 작가가 그린 느낌)
- [ ] 4종이 **명확히 구별**되는가? (시바·푸들·코숏·러시안블루 식별 가능)
- [ ] 색감이 너무 튀는 종이 없는가? (한 종만 채도 높음 등)
- [ ] 모든 캐릭터가 **위협적이지 않고 친근**한가?
- [ ] 페르소나가 직관적으로 느껴지는가?
  - 시바 = 의욕적·활발한 인상
  - 푸들 = 단정·섬세한 인상
  - 코숏 = 독립적·여유로운 인상
  - 러시안블루 = 차분·감수성 있는 인상

→ **하나라도 어색하면 해당 종만 재생성** (다른 종은 reference로 유지)

→ **모두 OK면 2일차로**

# 2일차 — 시바이누 변형 23장

**목표**: 시바이누 키 이미지 기반 표정 5종 + 트렌드 18종 = 23장.

**작업 채팅**: 1일차 시바 채팅 세션 그대로 이어가기 (외형 컨텍스트 유지). 끊겼으면 새 채팅 + `shiba/calm_stable.png` reference 업로드.

**시작 메시지** (새 채팅 시):
```
이 이미지의 시바이누 캐릭터를 reference로, 다양한 표정과 자세 베리에이션을 만들 거야.
외형(털색, 체형, 귀 모양, 눈 크기)은 동일하게 유지하고, 표정과 포즈/배경만 바꿔줘.
```

### 2-A. 표정 변형 5장 (배경은 stable 유지)

각 프롬프트를 한 번에 1개씩 요청. 결과 마음에 들면 저장, 아니면 미세 조정.

#### 2-A-1. shiba × happy × stable

```
이전 시바이누 캐릭터로, 표정만 바꿔서:
- 반짝이는 반달 눈 (초승달 모양)
- 활짝 웃는 입, 분홍 혀가 살짝 나옴
- 쫑긋 선 귀, 옅게 빛나는 아우라
배경과 자세는 이전과 동일 (아늑한 실내, 따뜻한 햇살, 머그컵).
```
**저장**: `shiba/happy_stable.png`

#### 2-A-2. shiba × neutral × stable

```
이전 시바이누 캐릭터로, 표정만 바꿔서:
- 동그란 평상시 눈
- 일자로 다문 입, 평이한 표정
- 자연스러운 위치의 귀
배경과 자세는 이전과 동일.
```
**저장**: `shiba/neutral_stable.png`

#### 2-A-3. shiba × sad × stable

```
이전 시바이누 캐릭터로, 표정만 바꿔서:
- 처진 눈꼬리, 작은 눈물 한 방울
- 입꼬리가 아래로 내려간 입
- 축 처진 귀
배경과 자세는 이전과 동일.
```
**저장**: `shiba/sad_stable.png`

#### 2-A-4. shiba × angry × stable

```
이전 시바이누 캐릭터로, 표정만 바꿔서:
- 찡그린 눈썹 (V자), 살짝 좁아진 눈
- 굳게 다문 입, 작은 송곳니가 살짝 보임
- 뒤로 젖혀진 귀, 약간 부푼 볼
배경과 자세는 이전과 동일. (귀엽고 무섭지 않게)
```
**저장**: `shiba/angry_stable.png`

#### 2-A-5. shiba × anxious × stable

```
이전 시바이누 캐릭터로, 표정만 바꿔서:
- 동공이 작아진 큰 눈, 옆을 살짝 본다
- 약간 벌어진 입
- 떨리는 귀, 머리 옆에 작은 땀방울 하나
배경과 자세는 이전과 동일.
```
**저장**: `shiba/anxious_stable.png`

### 2-B. 트렌드 변형 18장 (6표정 × 3트렌드: rising/declining/crashing)

표정은 이미 5+1=6개 만든 것 기준. 각 표정 × 3트렌드 = 18장.

**작업 효율 팁**: 하나의 트렌드(예: rising)를 6표정 전부 먼저 만들고, 다음 트렌드(declining)로 넘어가는 게 배경 일관성에 좋음.

#### 2-B-1 ~ 6. shiba × {6 emotions} × rising

각 프롬프트 베이스:
```
이전 시바이누 캐릭터로, 표정은 [EMOTION 키워드]로, 자세/배경은 다음으로 변경:
포즈: 기쁘게 점프하거나 달리는 모습, 앞발 또는 팔을 위로 들고 있음
배경: 새벽빛, 떠오르는 해, 가벼운 산들바람, 종이비행기 또는 풍선이 옆에 떠 있음
```

각 표정별 키워드 그대로 사용 (위 2-A 참고):

- happy: 반짝이는 반달 눈, 활짝 웃는 입, 분홍 혀 → 저장: `shiba/happy_rising.png`
- calm: 부드럽게 감긴 눈, 작은 미소 → 저장: `shiba/calm_rising.png`
- neutral: 동그란 평상시 눈, 일자 입 → 저장: `shiba/neutral_rising.png`
- sad: 처진 눈꼬리, 눈물 한 방울 → 저장: `shiba/sad_rising.png`
- angry: V자 눈썹, 송곳니 → 저장: `shiba/angry_rising.png`
- anxious: 작은 동공, 떨리는 귀, 땀방울 → 저장: `shiba/anxious_rising.png`

#### 2-B-7 ~ 12. shiba × {6 emotions} × declining

각 프롬프트 베이스:
```
이전 시바이누 캐릭터로, 표정은 [EMOTION 키워드]로, 자세/배경은 다음으로 변경:
포즈: 어깨가 처지고, 앞발 위에 턱을 괴고 생각에 잠긴 모습
배경: 흐린 늦은 오후 하늘, 부드러운 우수적 톤, 식어가는 찻잔
```

표정 키워드는 위와 동일. 저장:
`shiba/happy_declining.png`, `shiba/calm_declining.png`, `shiba/neutral_declining.png`, `shiba/sad_declining.png`, `shiba/angry_declining.png`, `shiba/anxious_declining.png`

#### 2-B-13 ~ 18. shiba × {6 emotions} × crashing

각 프롬프트 베이스:

## 부록 — 자주 발생하는 문제

| 문제 | 원인 | 해결 |
|---|---|---|
| 캐릭터가 한 채팅 안에서 점점 달라짐 | 컨텍스트 누적, 모델이 새 외형 학습 | reference 이미지 재첨부 |
| 표정이 너무 미묘함 | 키워드가 약함 | "매우 + [키워드]" 강조, 예: "매우 슬픈 처진 눈" |
| 배경이 무서워 보임 | crashing 표현이 과함 | "따뜻한 위로 분위기" 강조 추가 |
| 종이 잘못 그려짐 | 종명 인식 실패 | 영문 학명 포함, 예: "Russian Blue cat (Russian breed, silver-blue coat)" |
| 매번 다른 스타일 | 채팅 세션 분리됨 | 가능하면 한 종은 한 세션, 끊겼으면 reference 재첨부 |
