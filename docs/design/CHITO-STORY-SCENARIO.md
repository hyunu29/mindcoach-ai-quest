# 치토 스토리 시나리오 — 앱 전체 내러티브 설계

> 마이치의 모든 화면을 하나의 이야기로 묶는 설계 문서.
> 레퍼런스: 청월당(몰입형 캐릭터 스텝 퍼널) × 상냥이(라이트 SaaS 문법) — `DESIGN-TEMPLATES.md` 참고.
> 원칙: 치토는 "기능 안내 마스코트"가 아니라 **여정을 함께 걷는 동반자**. 모든 대사는 반말·1인칭, 명령하지 않고 제안한다.
> 워딩 금지: "전문 검사"(→ 간이 심리검사), "심리 상담"(→ 심리코칭), 의료·진단 오인 표현.

---

## 1. 세계관 (한 문단)

치토는 감정을 있는 그대로 느끼며 자라는 작은 감자다. 머리의 새싹은 마음이 자란 만큼 돋아난다.
치토는 수험생의 마음속 어두운 밤(다크 네이비)에 살고 있다 — 시험 불안이 만든 밤이다.
사용자가 자기 마음을 들여다볼 때마다 치토 주변에 빛(보라 글로우)이 켜진다.
**"네 마음을 확인하는 만큼, 치토의 밤이 밝아진다"** — 다크 배경은 버그가 아니라 세계관이다.
단, 라이트 UI 위에 놓일 때는 반드시 "밤을 담은 창문"(다크 라운드 카드 + 글로우 링)으로 프레이밍한다. 잘린 검은 사각형으로 노출되면 안 된다.

## 2. 치토 화법 규칙

- 반말, 짧은 문장, 자기 이야기를 섞음 ("나도 그럴 때 있어")
- 사용자를 평가하지 않음. "잘했어" 대신 "와줘서 고마워", "말해줘서 고마워"
- CTA 레이블은 UI 명령어가 아니라 **사용자의 대답** ("응, 좋아" / "내 마음 확인해볼래")
- 위험 신호 상황에서는 장난기를 빼고 차분하게, 전문가 연계 안내

## 3. 유저 여정 시나리오

| # | 터치포인트 | 치토의 역할 | 핵심 대사 (예) | 연출 |
|---|---|---|---|---|
| 0 | 랜딩 | 첫 만남 — 살짝 보이는 존재 | (대사 없음, 다크 카드 속 미소) | 히어로 다크 카드 + 우하단 플로팅 CTA ✅ |
| 1 | 검사 인트로 | 말을 거는 친구 | "안녕, 나는 치토야. 요즘 마음이 어떤지 물어봐도 될까?" | 다크 풀스크린 2스텝 게이트 ✅ (INT→전 검사 확대) |
| 2 | 검사 진행 | 질문하고 들어주는 친구 | 마일스톤: "벌써 절반이야. 솔직하게 말해줘서 고마워" | 다크 몰입 모드, 문항 슬라이드 전환, 진행바 |
| 3 | 검사 제출 | 결과를 정리하는 친구 | "잠깐만, 네 마음을 정리하고 있어…" | 다크 로딩 씬, 치토 + 글로우 펄스 |
| 4 | 결과 | 해석해주는 친구 | "이건 네가 이상한 게 아니라, 마음이 보내는 신호야" | (추후) 결과 상단 치토 코멘트 카드 |
| 5 | AI 코칭 | 대화 상대 | (기존 코칭 대화) | 치토 아바타 = 엠블럼 |
| 6 | 감정 기록 | 매일 만나는 친구 | "오늘 하루는 어땠어?" | (추후) 기록 완료 시 치토 리액션 |
| 7 | 대시보드 | 마중 나오는 친구 | 말풍선: "왔구나! 오늘 마음은 어때?" (감정 기록 여부·주간 추이에 따라 분기) | 다크 카드 치토 + 말풍선, 감정별 표정 |
| 8 | 친구 초대·공유 | 함께 소개하는 친구 | "네 친구 마음도 궁금하지 않아?" | 공유 카드 (기존) |

### 대시보드 말풍선 분기 (구현 사양)

- 오늘 감정 기록 없음: "왔구나! 오늘 마음은 어때? 나한테 들려줄래?"
- 오늘 기록 있음: "오늘 이야기 들려줘서 고마워. 네 덕분에 내 밤이 조금 밝아졌어."
- 주간 추이 상승: "요즘 네 마음, 조금씩 가벼워지고 있는 게 느껴져."
- 주간 추이 하락: "요즘 좀 무거웠지? 그래도 여기 와줘서 고마워."

### 검사 진행 마일스톤 (구현 사양)

- 25%: "잘하고 있어. 천천히 해도 돼."
- 50%: "벌써 절반이야. 솔직하게 말해줘서 고마워."
- 75%: "거의 다 왔어. 조금만 더!"

## 4. 치토 배경 문제 — 처리 전략

원본 `public/chito/*.webp`는 검은 배경이 이미지에 박혀 있음.

1. **단기 (CSS, 적용됨)**: `CharacterAvatar`에 프레이밍 내장 — 다크 라운드 카드 + 보라 글로우 섀도 + 링. "밤을 담은 창문" 프레이밍으로 어디서든 의도된 룩으로 보이게. (별도 ChitoPortrait 컴포넌트 대신 기존 공용 컴포넌트를 강화)
2. **장기 (자산 재생성, 사용자 액션)**: ChatGPT 이미지 생성으로 투명 배경 버전 제작 → `public/chito/transparent/`에 추가. 아래 프롬프트 사용.

### ChatGPT 이미지 생성 프롬프트 (복붙용)

원본 main.webp(또는 감정별 webp)를 **첨부하고** 아래 프롬프트 입력:

```
첨부한 캐릭터(치토, 감자 캐릭터)를 완전히 동일한 스타일·비율·표정으로 유지하면서,
배경만 100% 투명(transparent PNG)으로 다시 그려줘.
- 캐릭터 주변의 검은 배경과 글로우 효과를 모두 제거
- 외곽선과 셀 셰이딩 스타일 유지
- 캐릭터가 잘리지 않게 전신 포함, 정사각형 캔버스
- PNG, 투명 배경
```

추가 포즈 제작 (스토리 연출용 — 동일하게 원본 첨부 후):

```
첨부한 치토 캐릭터와 완전히 동일한 스타일로, 투명 배경 PNG로 다음 포즈를 그려줘:
1) 손을 흔들며 인사하는 포즈 (waving)
2) 골똘히 생각하는 포즈 (thinking, 머리 위 물음표)
3) 두 팔 벌려 환호하는 포즈 (cheering, 머리 위 반짝이)
4) 이불 덮고 잠든 포즈 (sleeping)
스타일 유지 조건: 둥근 감자 몸, 머리 위 새싹, 볼터치, 셀 셰이딩, 굵은 외곽선
```

투명 자산이 도착하면: `chito.ts`에 `CHITO_TRANSPARENT_URL` 추가 → 라이트 UI(대시보드, 채팅 목업)는 투명 버전, 다크 몰입 씬(인트로·검사)은 기존 버전 사용.

## 5. 모션 언어 (공용 규칙)

| 모션 | 용도 | 구현 |
|---|---|---|
| reveal-up | 섹션·카드 진입 | 기존 `.animate-reveal-up` |
| question-in | 검사 문항 전환 | `slide-in-right 0.35s` (다음) — key 교체로 재생 |
| chito-float | 치토 idle | `translateY ±6px 3s ease-in-out infinite` |
| glow-pulse | 로딩·제출 씬 | 글로우 opacity 0.6↔1 2s infinite |
| pop-in | 말풍선·마일스톤 등장 | `scale 0.9→1 + fade 0.25s` |

접근성: `prefers-reduced-motion: reduce`에서 무한 애니메이션(chito-float, glow-pulse) 비활성.
