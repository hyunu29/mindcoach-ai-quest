# 마이치 디자인 레퍼런스 템플릿

> 외부 레퍼런스에서 추출한 디자인 언어를 마이치 스택(Tailwind + shadcn/ui + CSS 변수)에 매핑한 문서.
> 픽셀 복제가 아니라 **스타일 언어(위계·여백·곡률·모션 톤)** 를 가져오되, 마이치 브랜드(치토·보라 계열·Pretendard)를 유지한다.
> 분석일: 2026-08-29 · 분석 도구: 브라우저 실측(computed style)

---

## 레퍼런스 A — 청월당 (cheongwoldang.com)

사주 콘텐츠 판매 랜딩. **몰입형 캐릭터 스토리텔링 퍼널**이 핵심 자산.

### 실측 토큰

| 항목 | 값 |
|---|---|
| 폰트 | Pretendard Variable (마이치와 동일) |
| 컨테이너 | **448px 고정 중앙 컬럼** — 데스크톱에서도 모바일 뷰 유지 |
| 배경 | 다크 네이비 밤하늘 (#0B1230 계열) + 풀블리드 시네마틱 일러스트 |
| CTA 버튼 | h48 · radius 8px · 18px/600 · **밝은 그라데이션** `linear-gradient(91deg, #C9E0FF → #FFF)` · 텍스트 #04336D · 글로우 `0 0 5px rgba(241,241,255,.4)` |
| 대사 텍스트 | 명조/붓글씨 느낌 세리프 + 따옴표 인용 ("...") |

### 핵심 패턴 (마이치가 가져올 것)

1. **스텝 기반 몰입 퍼널** — URL `?step=greeting → intro → 이름 → …`. 한 화면에 질문 하나. 뒤로가기 화살표 하나 외 크롬 없음.
2. **캐릭터가 직접 말을 건다** — 풀스크린 캐릭터 일러 + 하단 인용 대사. 정보 수집(이름·생년월일)을 "대화"로 포장.
3. **대화형 CTA 레이블** — 버튼이 UI 명령어가 아니라 사용자의 대답: "좋아요, 제 이름은..". 클릭이 대화 참여가 된다.
4. **다크 위 발광 CTA** — 어두운 배경에서 CTA만 밝게 빛나게. 시선 유도가 자연스럽다.

### 마이치 적용처: INT 통합검사 인트로 (백로그 — 대형 작업)

치토 확정 일러가 **다크+글로우 스타일이라 톤이 정확히 일치**한다. 검사 시작 전 몰입 게이트:

- `/tests/INT` 진입 시: 다크 네이비(#0c0e18) 풀스크린 + 치토 메인 일러 + 인용 대사
- 대사 예: "안녕, 나는 치토야. 시작하기 전에… 요즘 마음이 어떤지 물어봐도 될까?"
- CTA 레이블: "응, 좋아" / "내 마음 확인해볼래" (대화형)
- 문항 진행도 스텝 단위 풀스크린, 상단 진행바만 표시
- CSS: `bg-[#0c0e18]` + 보라 radial glow + CTA `bg-gradient-to-r from-[#E4E5FF] to-white text-[#2A2D8F]`

## 레퍼런스 B — 상냥이 (sangnyang.ai)

청소년 정서·진로 케어 AI (마이치와 동일 카테고리, B2B 학교향). **라이트 SaaS 랜딩 문법**이 핵심 자산.

### 실측 토큰

| 항목 | 값 |
|---|---|
| 폰트 | Pretendard (마이치와 동일) |
| 포인트 컬러 | #7761FF (마이치 #6466F1과 근접 — 우리 primary 그대로 사용) |
| 잉크 | #333 (헤드라인 검정에 가깝게) |
| 히어로 H1 | **48px / lh 72px(1.5) / weight 700 / letter-spacing -2%** — 크고 촘촘한 검정 볼드 |
| 주요 버튼 | **필(pill) 형태** radius 80~200px · h52~60 · 16px/600~700 |
| 버튼 배리언트 | ① 보라 솔리드(#7761FF·흰글자) ② 잉크 솔리드(#333·흰글자) ③ 연보라 소프트(#EBE8FF·보라글자) |
| 아이브로우 | 섹션마다 그라데이션 텍스트 소제목 ("Service Flow", "For Students") → 큰 볼드 헤드라인 2줄 |

### 핵심 패턴 (마이치가 가져올 것)

1. **아이브로우 → 헤드라인 위계** — `그라데이션 12~18px 볼드 라벨` + `2줄 대형 잉크 헤드라인`. 모든 섹션 헤더 통일.
2. **이모지 칩 클라우드** — 고민 키워드를 이모지+텍스트 pill로 흩뿌림 (🏫 학교폭력 · 😰 스트레스 · 😨 불안…). 흰 배경 · 얇은 보더 · 옅은 그림자 · rounded-full. 캐릭터 일러 주변에 배치.
3. **채팅 목업 플로팅 카드** — 실제 대화 스크린샷풍 카드가 섹션에 겹쳐 떠 있음. AI 대화 제품의 실체감.
4. **신뢰 배지 카드 행** — 인증·선정 이력을 로고+2줄 텍스트 카드 5개 행으로.
5. **플로팅 마스코트 CTA** — 우하단 고정: 소프트 버튼("소개서 다운") + 솔리드 필 버튼("도입 문의") 위에 마스코트가 걸쳐 있음.
6. **잉크/보라 이원 CTA** — 주 CTA는 보라, 부 CTA는 잉크 솔리드. 흰 배경에서 대비 강함.

## 마이치 매핑 (Tailwind / CSS 변수)

기존 토큰 유지: `--primary: 239 84% 67%` (#6466F1) · `--secondary: 263 70% 58%` · `gradient-primary` · Pretendard Variable.

| 패턴 | 구현 |
|---|---|
| 대형 잉크 헤드라인 | `text-[2.5rem] md:text-6xl font-bold text-foreground tracking-[-0.02em] leading-[1.28]` |
| 아이브로우 라벨 | `gradient-text text-sm md:text-base font-bold` (기존 `.gradient-text` 유틸 재사용) |
| 필 버튼 (주) | `rounded-full h-13 px-8 gradient-primary text-white font-bold` |
| 필 버튼 (부·잉크) | `rounded-full h-13 px-8 bg-foreground text-background font-bold` |
| 필 버튼 (소프트) | `rounded-full bg-primary/10 text-primary font-semibold` |
| 이모지 칩 | `rounded-full bg-card border border-border/60 shadow-sm px-4 py-2 text-sm font-semibold` |
| 다크 몰입 배경 | `bg-[#0c0e18]` + `radial-gradient(rgba(100,102,241,.25), transparent)` 글로우 레이어 |
| 다크 위 발광 CTA | `bg-gradient-to-r from-[#E4E5FF] to-white text-[#2A2D8F] shadow-[0_0_20px_rgba(164,166,255,.35)]` |
